1. Introduction

This Privacy Policy describes how the Nexabot Batch Automation Chrome extension (the “Extension”) processes information. The Extension automates batches of video-generation prompts on nexabot.id. It interacts with the Nexabot website using the page interface in your browser; it is not a standalone video-generation service.

When you start a generation batch, the prompts and any reference images you select are supplied to Nexabot through its website interface. Information handled by Nexabot is subject to Nexabot's own policies and practices, which are outside the Extension developer's control.

2. Information We Process

The Extension processes the following information to provide its features:

  • Prompts and generation settings: prompt text you enter, video mode, aspect ratio, resolution, and prompt/reference-image associations.
  • Reference images: image files you select for Ingredients mode. The Extension reads these in the popup and temporarily passes their contents to the Nexabot page when the associated job runs.
  • Batch and download status: queue and job identifiers, job status, retry/error details, timestamps, download method, and the resulting local filename/path when Chrome provides it.
  • License information: the license key you enter, a randomly generated device identifier, and the license-validation response/status.
  • Download metadata: when needed to monitor an Extension-initiated Nexabot video download, Chrome download identifiers and status, filename, MIME type, and byte count. If you use the download-check feature, the Extension reads recent Chrome download entries and displays matching video filenames.
  • Nexabot page information: the Extension checks the Nexabot generator page's controls and visible status/result elements to operate the interface, detect generation completion or errors, and initiate and monitor downloads.

The Extension's inspected source contains no analytics or telemetry integration, and no other network request mechanism was found in its JavaScript. The Nexabot website itself may use its own scripts, storage, network services, and account data; this policy does not describe those practices.

3. How We Use Information

We use prompts and settings to populate Nexabot's generator and run the batch you request. Reference images are attached to the relevant Nexabot job when you select Ingredients mode. Page information and download metadata let the Extension track job progress, recover queue status, and confirm that a video download has completed. License information is used to activate and validate the Extension's license.

4. Local Data Storage

The Extension uses Chrome's chrome.storage.local to keep the batch queue (including prompts, settings, status and errors), temporary download-monitoring state, the license key, device identifier, and license response in your browser profile. Queue data is removed when you use the Extension's clear/reset action. That action does not remove the stored license key or device identifier. Chrome manages the Extension's local storage; uninstalling the Extension normally removes its extension storage.

Selected image contents are held in memory while the popup and content script pass them to the Nexabot page; the inspected code does not save image contents in chrome.storage.local. Chrome separately manages downloaded video files and its download history according to your browser settings. The Extension may read download metadata as described above.

5. Third-Party Services (Nexabot)

Nexabot: when you run a batch, the Extension places each prompt into the Nexabot video-generator page and activates its Generate control. In Ingredients mode, it also places the reference image or images you selected into that page. Nexabot receives this material through the website's normal interface and processes the generation. The Extension also reads the resulting video element and uses its download control or video URL to download the result through Chrome. Nexabot's own terms, privacy policy, retention, and processing practices govern its service.

License validation service: the Extension sends your license key and generated device identifier in HTTPS POST requests to nexabot-license-server.frangga-snow.workers.dev for license activation and validation. The response is stored locally as license status. The inspected Extension source does not establish who operates this endpoint or how long the service retains data. Confirm its operator and handling practices before publishing.

Video media may be downloaded from the URL exposed by Nexabot's page, or through Nexabot's own download button if direct downloading is unavailable. The specific media host may depend on Nexabot's implementation. The Extension source does not include a separate developer-operated video-processing server.

6. Data Sharing and Disclosure

The Extension sends prompts and selected reference images to Nexabot when you start generation, and sends license keys and the device identifier to the license-validation endpoint when checking or activating a license. These are distinct data flows for distinct services. Browser and network providers may also process connection or download information as part of providing their services.

The inspected Extension code does not send queue contents, selected images, or download history to the license endpoint, and does not contain analytics/advertising sharing code. This statement is limited to the Extension source reviewed; it does not cover data collected independently by Nexabot, Chrome, or the license service.

7. Data Security

Connections explicitly made by the Extension to Nexabot and the license endpoint use HTTPS. Local Extension data is stored in Chrome's extension storage within your browser profile. The inspected code does not encrypt the license key or queue data itself, so protect access to your browser profile and device. No method of transmission or storage can be guaranteed completely secure.

8. Browser Permissions

  • Storage: saves queue progress, download-monitoring state, and license data in the browser.
  • Downloads: starts and monitors video downloads, assigns a batch filename, and reads recent download metadata for its download-check feature.
  • Tabs: checks the active tab, opens or reloads the Nexabot generator when needed, communicates with the Nexabot page, and opens Chrome's download settings when requested.
  • Side panel: displays the Extension's interface from Chrome's side panel.
  • Site access: runs the content script on https://nexabot.id/* and accesses the license endpoint at https://nexabot-license-server.frangga-snow.workers.dev/* for the operations described in this policy.

9. Children's Privacy

The Extension is not intended for children under 13, and the developer does not knowingly seek to collect information directly from children. The Extension does not perform age verification. If you believe a child has provided information through the Extension or related services, contact the developer using the details below.
