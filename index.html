1. Introduction

This Privacy Policy explains how Nexabot Batch Automation (the “Extension”) processes information. The Extension automates video-generation batches through the Nexabot website at nexabot.id. It interacts with the generator page in your browser and uses the Nexabot service to generate videos.

The Extension handles user-provided prompts, optional reference images, batch progress, download metadata, and license information as described below. Some information stays in your browser; prompts and selected images are submitted to Nexabot, and license details are sent to the license service.

2. Data We Collect and Process

For the Extension's batch automation and license features, the Extension processes these categories of information:

  • Prompt and job data: text prompts, job and queue identifiers, video mode, aspect ratio, resolution, prompt order, image count, progress state, retry count, and error messages. Prompt text and job status are stored locally; prompts are also submitted to Nexabot when you run a batch.
  • Reference images: image files you choose for Ingredients mode, including their contents and file names while selected. Their contents are temporarily passed through the Extension to the Nexabot page for upload; the Extension does not write image contents to its local extension storage.
  • License data: the license key you enter, a randomly generated device ID, and the status and other response fields returned by the license service. The key and device ID are sent to the license service for activation and validation.
  • Page and download data: information read from the Nexabot generator page to operate its controls and detect visible generation results or errors; video media URLs exposed by that page; and Chrome download identifiers, status, filename, MIME type, byte count, and timing information used to monitor downloads. If you request the download check, the Extension searches up to 40 recent Chrome download entries and displays matching video filenames.
  • Browser context: the active tab's ID and URL are checked to ensure the batch runs on the Nexabot generator page. The Extension does not request the Cookies permission or use a cookies API.

The Extension source reviewed does not include an analytics or advertising SDK, or code that sends prompts, images, or download history to the license service.

3. How We Use Your Data

  • Prompts, settings, and selected images are used to submit the video-generation jobs you request on Nexabot.
  • Queue, page, and download information is used to run, resume, and show the status of your batch and to confirm downloads.
  • The license key and device ID are used by the license service to activate and validate your license and enforce its device binding.
  • Local storage preserves queue progress and license state between uses of the Extension.

FlowPilot limits its use of information handled by the Extension to the purposes described in this Policy and the Extension's single purpose. FlowPilot does not sell this information or use it for personalized advertising. Any transfer described here is made to provide the requested Nexabot generation or license feature. For information under FlowPilot's direct control, human access is limited to the exceptions permitted by the Chrome Web Store User Data Policy, such as a user's explicit consent for specific support, security needs, legal compliance, or aggregated and anonymized internal operations. FlowPilot's use of user data accessed by the Extension is subject to the Chrome Web Store User Data Policy, including its Limited Use requirements.

4. Prompt and Reference Image Processing

When you start a batch, the Extension places each prompt and the selected generation settings into the Nexabot video-generator page and activates the page's Generate control. In Ingredients mode, the Extension reads the image files you selected and places them into the Nexabot page's image input for the corresponding job. Nexabot receives and processes this content to generate the requested video.

The Extension does not store image contents in chrome.storage.local. It converts selected images to temporary in-memory data for transfer to the Nexabot page. The page and Nexabot service may process or retain submitted prompts, images, and resulting videos under their own service practices. This Extension does not set or control Nexabot's retention period.

5. License Verification and Device Identification

For activation and validation, the Extension sends the license key you entered and a randomly generated device ID to the Nexabot license service over HTTPS. The original key is transmitted so the service can validate it; the service does not store the original license key in plaintext in its database. It stores a hash of the key for matching.

After successful activation, the service stores the device ID, activation time, license validity period, and last validation time. The device ID binds one license to one device. The device-binding record remains until an administrator releases the binding or the license is deleted. Releasing a device binding does not necessarily delete all license-related records.

The license service is operated by the Nexabot developer using Cloudflare Workers. Cloudflare provides the infrastructure for the Worker requests. The license key and device ID are processed by the license service for validation, even though the original key is not stored there in plaintext in the database.

6. Local Browser Storage

The Extension uses chrome.storage.local in your Chrome profile for:

  • The batch queue, including prompts, settings, job states, errors, and download results.
  • Temporary download-monitoring state, such as a job index, tab/download identifier, and timestamps.
  • The license key, device ID, and license validation response.

These values are not synchronized by the Extension to a developer-operated storage service. The license key is stored in the browser's extension storage so it can be sent again for license validation; the Extension does not encrypt it separately before local storage. Selected image contents remain in memory for the transfer described above. Chrome stores downloaded video files and download history separately under your browser settings.

7. Data Transmission and Security

The Extension's license requests use HTTPS. Prompts and reference images are supplied to the Nexabot generator over the Nexabot website connection, which uses HTTPS. Video downloads are initiated by Chrome from the video URL exposed by Nexabot or by using Nexabot's own download control; the media host may be selected by Nexabot.

The Extension stores its local queue and license values in Chrome extension storage and does not apply separate encryption to those values. Protect access to your Chrome profile and device. Cloudflare Workers processes requests to the license service as its infrastructure provider; Cloudflare's applicable service terms and privacy practices apply to its infrastructure processing.

8. Data Sharing and Third-Party Services

  • Nexabot (nexabot.id): receives prompts, settings needed for a generation, and reference images you select, and returns the generated video through its website. The Extension uses the Nexabot page and does not provide a separate video-generation backend. Nexabot's own privacy and retention practices govern its service.
  • Nexabot license service and Cloudflare: the license service receives the license key and device ID for activation and validation. It runs on Cloudflare Workers, so Cloudflare provides the request-processing infrastructure. The Extension does not send the prompt queue, reference images, or download history to this license endpoint.
  • Chrome: Chrome provides local extension storage and the Downloads API. Chrome processes the download request and stores the downloaded file and browser download records according to Chrome's settings.
  • Video delivery host: a video host selected by Nexabot may receive the browser's request to download the generated video. The Extension cannot identify a fixed host in advance.

FlowPilot does not sell Extension data or share it with advertising networks. The Extension's transfers to Nexabot and the license service are limited to providing the features described in this Policy.

9. Data Retention and Deletion

  • Queue and download-monitoring data: retained in local extension storage until you use the Extension's clear/reset action, which removes the queue and download-monitoring state, or remove the Extension from Chrome.
  • Local license values: the license key, device ID, and license response remain in local extension storage. The clear/reset action does not remove them. Remove the Extension from Chrome to remove its extension storage; the license service's server-side records are not removed by this local action.
  • License service records: the service stores a hash of the license key and, after activation, the device ID and activation, validity, and last-validation information described above. A device-binding record remains until an administrator releases the binding or the license is deleted. No automatic deletion of all license data on unbinding is promised. A broader server-side retention period has not been specified.
  • Nexabot prompts, images, and generated videos: submitted to Nexabot for generation. Their retention and deletion are controlled by Nexabot; the Extension does not define a retention period or delete those service-side copies.
  • Downloaded files and Chrome download history: managed by Chrome and remain subject to the download location and history settings you choose. Delete them through Chrome or your device's file manager.
  • Cloudflare operational data: the Extension does not control Cloudflare's infrastructure data. Its handling and retention are governed by Cloudflare's applicable service terms and privacy practices.

10. Chrome Extension Permissions

  • Storage: saves the queue, download-monitoring state, and license details locally.
  • Downloads: starts video downloads, sets a batch filename, monitors completion, and reads recent download entries when you use the download-check feature.
  • Tabs: checks the active tab, opens or reloads the Nexabot generator, communicates with its page, and opens Chrome download settings when you request that action.
  • Side panel: displays the Extension interface in Chrome's side panel.
  • Host access: runs the content script on https://nexabot.id/* and allows HTTPS requests to https://nexabot-license-server.frangga-snow.workers.dev/* for the generation and license features described above.

11. User Rights and Choices

You choose whether to enter prompts, select reference images, activate a license, and start a generation. You can clear the locally stored queue and download-monitoring state with the Extension's clear/reset action. You can remove the Extension to remove its local extension storage. Manage downloaded files and Chrome download history through Chrome and your device.

For requests about license-service records, contact FlowPilot using the email below. Requests about prompts, images, account information, or videos submitted to Nexabot should be directed to Nexabot, because those records are handled by its service. The ability to access or delete a server-side license record may depend on the license service's verification and administrative process.

12. Children's Privacy

The Extension is not designed to collect personal information from children. The developer does not knowingly seek personal information directly from children through the Extension. The Extension does not independently verify a user's age. If you believe a child has submitted personal information through the Extension, contact FlowPilot using the address below.
